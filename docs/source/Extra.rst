------------------
Sample_setting.txt
------------------

| This file purposes is generated by PecubeGUI and is used to provide input parameters for the program CalcAge, it has no influence on Pecube itself. It is located in the "data" directory of the Pecube's project main directory. Here is the significance of each line of the file.

1. Name of sample data directory
2. Number of samples
3. Number of grains to predict
4. AHe flag, ZHe flag, AFT flag, KAr flag, BAr flag, MAr flag, HAr flag, TL flag, OSL flag, ESR flag #Thermochronometer to compute 
5. do 4He/He3 predictions? (yes = 1; no = 0)
6. Zonation ? (yes = 1; no = 0, not working in the current version, keep default 0 value)
7. Write each sample information (sample ID,  longitude, latitude, elevation) - one line per sample
8. Number of grain for each sample - one line per sample
9. Alpha Ejection model (dummy now), Alpha ejection distances flag (0: Farley et al. (1996), 1: Ketcham et al., (2020)), Helium Diffusion model flag, D0, Ea, rmr0 #AHe
10. helium Diffusion model flag, D0, Ea #Zircon
11. FT annealing model flag, rmr0 #AFT
12. D0, Ea #Feldspar
13. D0, Ea #Biotite
14. D0, Ea #Muscovite
15. D0, Ea #Hornblende
